How to build a week

  1. Open the editor
    Click "Open editor" above. If you've worked on this week before, click Load draft to pick up where you left off.
  2. Set the week date (section 00)
    Pick the Monday of the week. The folder name updates automatically.
  3. Fill in what you've got
    Type into any field. Leave fields blank for "to confirm" placeholders. Auto-saves to your browser as you type, so you can close the tab and come back.
    Files: 2 IG post images (jpg/png), 5 IG story videos (MP4 best, MOV ok), optional website mockup. Stories must be 1080×1920.
  4. Paste the email + website HTML
    For Email Campaign: paste the Klaviyo/TalkBox HTML (style block + body content, no outer shell).
    For Website Updates: paste the Squarespace HTML/Liquid block.
  5. Preview before generating
    Click Preview in the editor sidebar. A new tab opens showing exactly what Jordan will see. If it looks right, close the tab and continue.
  6. Generate the zip
    Click Generate zip. A file called week-YYYY-MM-DD.zip downloads to your Downloads folder.
  7. Drop it into the repo
    Open Terminal and run: cd ~/APPS/jordys-hub unzip -o ~/Downloads/week-YYYY-MM-DD.zip -d weeks/YYYY-MM-DD/ Replace YYYY-MM-DD with the week's Monday. The -o flag overwrites, the -d flag puts files in the right folder.
  8. Push to GitHub
    git add . git commit -m "Week of [date]" git push Live within ~30 seconds at mellyanncox-ctrl.github.io/jordys-hub/weeks/YYYY-MM-DD/.
  9. Send Jordan the link
    He reviews, hits Approve or Request Changes on each section, you get the email.
02

When things go wrong

  1. Image or video not showing on live site
    GitHub Pages is case-sensitive. If the file is IMG.JPG but the page wants ig-post-1.jpg, it 404s. Fix: rename to lowercase. cd ~/APPS/jordys-hub/weeks/YYYY-MM-DD git mv IG-POST-1.JPG ig-post-1.jpg git commit -m "lowercase filename" git push Use git mv not plain mv; macOS is case-insensitive locally so plain mv does nothing.
  2. Story video shows black box on Android
    MOV files don't always play on Android Chrome. Re-export from your editor as MP4 (H.264) and replace the file in the week folder.
  3. Editor draft is gone
    Drafts live in the browser's localStorage, scoped to whatever device + browser you used. They survive tab closes and computer restarts, but not browser changes (Chrome → Safari) or clearing site data.
  4. Pushed but the live site hasn't updated
    GitHub Pages takes 30-60 seconds to rebuild. If still nothing after 2 minutes, check GitHub Actions for a failed deploy.

How to add a date triggered flow

  1. Build the email HTML in your editor
    Use the Welcome template as a base. Subject + preview lines should start with a capital letter, body copy stays lowercase Jordy voice. Strip em dashes (use | instead).
  2. Drop the file into flows/
    Save as flows/<slug>.html (e.g. welcome-1.html, milestone-5.html). The slug becomes the URL.
  3. Add it to the FLOWS list in build.py
    At the top of build.py, add a new entry to the FLOWS array. Set status to "review" when ready for Jordan, or "building" while still drafting. { "slug": "milestone-20", "name": "Milestone 20", "where": "TalkBox > Automations > Milestone Flow", "week": 5, "status": "review", "timing": "Sends within 24 hours of 20th visit", "subject": "You're basically family", "preview": "20 visits is a lot", },
  4. Rebuild and push
    cd ~/APPS/jordys-hub python3 build.py git add . git commit -m "Add <flow name>" git push
  5. Send Jordan the link
    The new card appears at /flows/. Jordan reviews + approves inline; you get the email.
04

How to add a recurring flow

  1. Build the email HTML
    Same template pattern as date triggered flows. Save to recurring/<slug>.html.
  2. Add to the RECURRING list in build.py
    The RECURRING array sits below FLOWS. Pick a theme (Christmas / EOFY / Other) and set send_order to position it within that theme. { "slug": "valentines", "name": "Valentine's Day", "theme": "Other", "send_label": "Every year on February 7th at 11:00 AM", "send_order": 4, "recipients": "All contacts", "where": "TalkBox > Recurring", "status": "review", "subject": "Couples that pizza together", "preview": "Stay together", },
  3. Rebuild and push
    Same as flows: python3 build.py then git add . && git commit && git push.
05

How to add a campaign report

  1. Save the report HTML
    Drop it into reports/<slug>.html (e.g. week-5.html, may-2026.html). The full report opens in a new tab when Jordan clicks "Open report".
  2. Add to the REPORTS list in build.py
    { "slug": "week-5", "title": "Campaign 5", "subtitle": "Weekly campaign report", "date": "Week 5", "sort_date": "2026-05-12", "kind": "weekly", "summary": "Per-campaign attribution: Klaviyo opens and clicks, dine-in matches, me&u orders.", }, sort_date orders the cards (newest first). kind is "weekly" or "monthly".
  3. Rebuild and push
    The card auto-appears on /reports/ in the right section.
